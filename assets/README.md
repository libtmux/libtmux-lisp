# Logo assets

SVG and 512 x 512 transparent PNG artwork from the private `libtmux/assets`
kit, revision `ef6c550b8d1120fe6873e610ddbe550f95016a46`
(`assets/lisp/library`).

Library marks use the tiled libtmux base with its cog. Common Lisp's primary
tile is `#3FB68B` from the pinned
[GitHub Linguist palette](https://github.com/github-linguist/linguist/blob/538da05f034fa5c83bd81df128d144e208898da3/lib/linguist/languages.yml),
with the family's OKLab shade adjustments on the upper and lower tiles. The
source libtmux and tmuxp paths belong to the project owner.

- `logo.svg` (`5893` bytes): SHA-256
  `6235af4b33af33c0895d103933f0f201c42620c2494f6ec95f356df83d2849ec`
- `logo.png` (`16051` bytes, from `logo-512.png`): SHA-256
  `73aeafac0aa3944aaba1c36fcc51700917f66b33f0600dd2578793586475c924`

The root and secondary ASDF system READMEs embed these local files.
`.github/social-preview.png` holds the 1200 x 630 light Open Graph card for
GitHub's **Settings -> Social preview** upload, and shared site icons live in
`libtmux/docs` under `site/public/brand/lisp/`.
